# Mリーグ速報（非公式ビューア）

Mリーグ公式サイト（m-league.jp）の公開情報をまとめて、スマホでアプリのように見られるようにした個人用ビューアです。

- **日程**: 今日／次の対局、シーズン全日程（月ごと・1卓目／2卓目）、推しチームの卓を緑で色付け、推しチームの試合だけ表示
- **推しチーム**: 右上の★から1チーム選択（順位表のチーム詳細からも設定可）
- **順位**: チーム順位表、ポイント推移グラフ（最大3チームを色付きで比較）
- **個人**: 今季は11項目、通算（2018-19〜）は6項目で並べ替え。選手をタップすると今季の詳細・対局履歴と、シーズン別の通算成績（いずれもレギュラーシーズン）
- **結果**: 試合結果の履歴（チームで絞り込み）

## しくみ

```
GitHub Actions (5分おき) ──> scraper/scrape.py ──> docs/data.json（今季）と docs/history.json（過去）をコミット
                                                        │
GitHub Pages (docs/) ──> スマホ/PC のブラウザ ──> 開いている間は1分ごとに data.json を再読込
```

- 対局のある時間帯（19:00〜翌1:00 JST）は5分おき、それ以外は毎日3:00に全日程を取り直します。
  GitHub のスケジュール実行は混雑時に数分〜十数分遅れることがあります。
- 中身が変わったときだけコミットするので、試合のない日はコミットが増えません。
- 公式サイトへのアクセスは1回の更新につき4ページ程度、1.5秒間隔です。

### データの出どころ

| 内容 | 公式サイトのページ | ファイル |
|---|---|---|
| 順位・日程・試合結果 | トップ / 試合日程（月別） | data.json |
| 今季の個人成績（レギュラー） | 成績（レギュラーシーズンのタブ） | data.json |
| 過去シーズンの個人成績（レギュラーのみ） | 各チームページの「対戦成績」 | history.json |
| 過去シーズンのチーム成績（レギュラー） | 累計ポイントページのデータ | history.json |

成績はすべてレギュラーシーズンのみを扱います（セミファイナル・ファイナルは表示しません）。
チームページの過去成績は5項目だけなので、毎日の更新で今季の全項目を `history.json` の `archive` に保存し、翌シーズン以降も詳しく見られるようにしています。

### ファイル構成

```
scraper/
  scrape.py          取得の流れと JSON の書き出し
  common.py          取得・数値変換・チーム一覧
  parse_live.py      今季のページの解析
  parse_history.py   過去シーズンの解析
docs/
  index.html, style.css, sw.js, manifest.webmanifest
  js/main.js         起動・タブ・自動更新
  js/store.js        状態と読み込み
  js/model.js        集計（通算・ポイント推移など）
  js/components.js   共通部品 / js/chart.js グラフ / js/sheets.js 詳細シート
  js/views/*.js      各タブの画面
```

## ホーム画面に追加

- iPhone: Safari で開く → 共有ボタン → 「ホーム画面に追加」
- Android: Chrome で開く → メニュー → 「ホーム画面に追加」／「アプリをインストール」

## 手元で動かす

```bash
pip install -r scraper/requirements.txt
python scraper/scrape.py --full
python -m http.server 8765 --directory docs
```

## 注意

- 非公式・個人利用のためのツールです。データの権利は M.LEAGUE に帰属します。
- 公式サイトの作りが変わるとデータ取得が止まります。Actions のログで `scrape.py` のエラーを確認してください。
- 60日間リポジトリに動きがないと GitHub がスケジュール実行を止めます（オフシーズン明けに Actions 画面から再開）。
